# Seusomelier

Landing page pessoal e microsite do perfil `@seusomelier`, com links para redes sociais, música, contato e demais canais digitais.

## Sobre o projeto

Este repositório contém uma página estática em HTML, CSS e JavaScript para apresentar uma identidade visual forte, com layout tipo link-in-bio e foco em personal branding.

A página principal está em `index.html`, com estilos embutidos e imagens locais na pasta `img`.

## Estrutura do projeto

- `index.html` — página principal da landing page
- `eco.html` — página complementar/ecossistema
- `img/` — arquivos visuais e imagens do projeto
- `404.html` — página de erro 404
- `CNAME` — configuração do domínio personalizado
- `robots.txt` — regras de indexação para motores de busca
- `sitemap.xml` — mapa do site para SEO

## Visualização online

O projeto está disponível em:

## Observações

- O site foi montado com foco em apresentação visual e links rápidos.
- O layout inclui elementos de identidade pessoal, mídia social e uma animação de introdução.
- O conteúdo e as imagens podem ser ajustados facilmente na estrutura HTML e na pasta `img`.
